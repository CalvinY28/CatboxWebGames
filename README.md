# Catbox Web Games

Catbox is a playful collection of homemade browser games built for quick rounds and friendly rematches.

The first release includes:

- Tic-Tac-Toe for two local players
- Connect Four for two local players
- Pocket Fleet, a compact naval strategy game against the computer

The games run entirely in the browser and require no account or download.

## Local development

```bash
npm run install:ci
npm run dev
```

Create a production build with `npm run build`.
