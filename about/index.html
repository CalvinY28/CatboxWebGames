About

A small home for homemade browser games.

Catbox Games

Catbox Games is my growing collection of small, homemade games. The goal is to make playful games that anyone can open in a web browser and enjoy without an account, download, or complicated setup.

What you'll find

The collection begins with familiar games such as Tic-Tac-Toe, with more ideas planned for the future. Some games can be played locally on one device, while others may let you invite a friend to play online.

Catvan Studio

Catvan Studio is the independent creative name behind this site. Catbox Games is a place for experimenting with game design, web development, and small interactive details that make the site feel fun to visit.
